# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, give and receive constructive feedback, and
focus criticism on the work rather than people. Maintainers may remove comments
or contributions that violate this standard. Report unacceptable behavior
privately through the security contact in `SECURITY.md`.
